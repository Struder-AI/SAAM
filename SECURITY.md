# Security policy

Report suspected security issues privately through the repository's GitHub
Security tab when private vulnerability reporting is available. Include the
affected revision/files and a minimal reproduction when possible. Avoid
posting sensitive details in a public issue.

The refresh currently contains documentation and repository checks. It has no
manufacturing runtime, hardware-control interface, or credential integration.
As these capabilities are built, review handling of untrusted geometry and
machine programs, private print data, and changes to approved artifacts.

A software check or preview does not establish a successful physical print.
Describe the scope of verification accurately.
