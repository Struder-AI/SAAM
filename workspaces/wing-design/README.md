# Wing design workspace

Development prototype for a specialized wing-design application. Its requested
workflow covers Use / Shape / Construction, source-backed airfoil selection,
controls and tails, reinforcement and fuselage attachment, with progressive CAD
and inspection. See the [design brief](../../skills/wing-design/DESIGN-BRIEF.md)
for requirements and the [current manual](../../skills/wing-design/SKILL.md) for
implemented capabilities and limits.

## Location and integration

Application code currently remains under `skills/wing-design/`. This directory
establishes its separate workspace record; migration has not been performed.
The prototype is a separate experience; its developmental geometry sample can
be imported through SAAM's shared print tools. Full aircraft design and validated
full-span printing are not established. Existing geometry tooling must be assessed
for reusable skill ownership when the application is moved.
