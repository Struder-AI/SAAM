SAAM — Builder Agent Context Map

A builder changes skills, extends Studio and makes isolated, local changes to core — and makes parts to test that work. Builder is the middle of three roles (maker → builder → developer), and builders inherit maker responsibilities. Vertical spine = the required start; a red arrow = an action (run builder-onboarding; later, read CONTRIBUTING before checkpoint/publish); sideways = references reached as the work needs them; blue dashed marks the orientation bundle; onboarding also supplies MAKERS, print tools and skill authoring. These navigation arrows are distinct from calculated red shared-use references on code maps. Click a box to open the file. Hover to isolate its links.

green dot = also MAKER context (the maker slice a builder inherits). Skill authoring and internals are builder work. Read relevant region maps before changing skills, Studio or isolated core behavior, so the change does not cross a boundary it cannot see. The tan boxes lower right lead to scoped implementation context and the map contract. Reading those sources does not change the builder role or authorize broader changes.
