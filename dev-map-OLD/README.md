# Archived developer maps

This folder holds historical comparison material and superseded map reviews.
It is not scanned, loaded as composition input, or used by the current viewer.

- `comparison-path-groups.json`: the former path-planning grouping retained for comparison.
- `view/comparison/`: the frozen comparison viewer and its generated assets.
- `audit/`: superseded CLI review snapshots, early probes, removed configurations and old logs.

Generated viewers and local audit artifacts remain git-ignored. Current generators,
configuration, tests and documentation live in [dev-map](../dev-map/README.md).
Baselines still needed for ongoing behavioral checks remain in `dev-map/audit/`.
