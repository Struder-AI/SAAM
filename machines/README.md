# Machine files

A machine file describes a machine and the output options it supports. An
export generated from SAAMpath must match one of those options.

No machine file is implemented in this refresh. The first machine, its setup,
and the file definition are deferred. Relevant setup information must be fixed
in the locked process plan before generation; exporting cannot introduce new
process choices.

See [GLOSSARY.md](../GLOSSARY.md) and [build requests](../build_request.md).
