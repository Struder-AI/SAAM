## Browser restoration

**Deferred to 0.5.0; outside [0.3.3](0.3.3.md). Implementation has not started.**

Returning to Studio through browser Back/Forward should restore the matching toolpath, machine model, pose and manual controls. Reconnect the event stream and reject obsolete worker replies.

Source inspection and a component probe found that page departure disposes the source worker, while restoration reuses a cached program and attempts to bind the closed session. The program returns but its machine scene does not. Evidence is scoped to those components; an actual browser Back/Forward reproduction remains pending. [Studio lifecycle](../studio/app.mjs), [source session](../studio/machine-session.mjs) and [cached presentation](../studio/studio-state.mjs) own the affected paths.

Acceptance: with supported machine output open in Studio, navigate away and return through a persisted browser page. Verify restored toolpath, model, pose, manual controls and live updates without a full reload or program change; no stale response may replace the current presentation. Settle the restoration design when this release work begins.

Adapt the entire thickness of participating non-principal layers as close as possible to their supplied spacing while fitting that cadence; leave nonparticipating layers nominal. Either or both references may be nonplanar. Interlocking requires a minimum shared-claim depth, provisionally 0.1 mm, controlled by one named code-level setting, independent of nozzle forgiveness (owner, 2026-10-15). ### Possibilities without a settled requirement

- Refine vase offerings and add Trace extensions for useful examples, using [0.3.1's extension format](0.3.1.md).
- Keep modulation applications beyond visual/surface effects open. A general technical modifier system is not a settled requirement; graded infill density was not requested.
