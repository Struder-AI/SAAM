# SAAM 0.4.0 Mac install trial

Thank you for testing. This is a **review build** (`0.4.0-review`): it never
offers updates, cannot be activated and sends no diagnostics. Use it for this
trial only; afterwards uninstall it or install the next published release.

## Which package

You need macOS 13.5 or later (Apple menu → **About This Mac**).

| Your Mac | Package |
| --- | --- |
| **Chip: Apple M…** | `SAAM-0.4.0-review-darwin-arm64.zip` |
| **Processor: Intel** | `SAAM-0.4.0-review-darwin-x64.zip` |

In Terminal, `sysctl -n hw.optional.arm64` prints `1` on Apple Silicon.

You will receive that ZIP, its `.zip.sha256` file and `INSTALL.md`. Put all
three in a new folder, for example `~/Downloads/saam-040`.

## Before installing

- **Mac without SAAM:** nothing to do.
- **Mac with SAAM 0.3.13:** note the version shown in Studio, then choose
  **Quit** in the SAAM menu-bar menu (or run `saam quit`). Your prints are kept
  and should still be there afterwards.

## Install

Ask desktop Codex or Claude Code:

> Install SAAM from the ZIP in ~/Downloads/saam-040, following INSTALL.md in
> that folder. Skip its download step; verify the checksum.

If you would rather do it yourself, in Terminal:

```sh
cd ~/Downloads/saam-040
shasum -a 256 -c SAAM-0.4.0-review-darwin-arm64.zip.sha256
unzip -q SAAM-0.4.0-review-darwin-arm64.zip
bash SAAM-0.4.0-review-darwin-arm64/app/packaging/macos/install.sh
```

(Use `darwin-x64` in all three names on an Intel Mac.) Do not use `sudo`, and do
not turn off Gatekeeper. If macOS blocks something, take a screenshot first.

## Checks to report

1. **Installer:** did it end with `SAAM 0.4.0-review application is installed.`?
   Did any macOS dialog or warning appear?
2. **Status:** in a new Terminal window, `saam status` shows version
   `0.4.0-review`. If `saam` is not found, run `~/SAAM/app/saam status` and say so.
3. **Studio:** Studio opened in your browser and a SAAM icon is in the menu bar.
4. **Example part:** in a new chat, ask "Start the SAAM tour". Follow Studio's
   lessons, change the fin, press Play, and at the last lesson export the file.
   Report whether each step worked and whether the exported file downloaded.
5. **Your chat app:** open a new Codex or Claude Code chat and ask "What SAAM
   version is running?". Report any restart, permission or trust prompt (Codex
   shows a yellow fishhook under the message box), and whether a request you
   send from Studio reaches the chat.
6. **0.3.13 upgrade only:** your earlier prints still appear in Studio.

## Send back

- The complete installer text from Terminal (or from the agent's chat).
- The output of `sw_vers`, `uname -m` and `saam status`.
- Screenshots of any warnings or errors.
- These files, if present: `~/SAAM/state/migration.json`,
  `~/SAAM/state/client-registration.json` and the folder `~/SAAM/tmp/diagnostics`.
- If SAAM did not start: run `~/SAAM/app/SAAM.command` and send what it prints.

## Uninstall

```sh
saam quit
bash ~/SAAM/app/packaging/macos/uninstall.sh --yes
```

This removes the application, `~/Applications/SAAM.app`, the desktop shortcut,
the PATH lines in `~/.zprofile` and `~/.bash_profile`, and the Codex and Claude
Code registrations. Your prints and settings stay in `~/SAAM/local`.
