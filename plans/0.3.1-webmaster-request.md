## Content contracts for 0.3.1

- **Geometry and toolpath:** explain Geometry construction/import/transform/query and Toolpath's Inject, Trace and Slice. SAAMpath is machine-independent; selected-machine compatibility, physical tools, startup/priming, machine clearance, axis limits and translation/checking belong to Export. Numeric authoring defaults can come from profiles. Output-only changes reuse unchanged neutral deposition.
- **Bundle and Studio:** a bundle holds supplied geometry, recipe, settings snapshots, revisions and artifacts. It need not already contain a machine or path; consuming operations state their prerequisites. One Studio instance owns a bundle association. One agent may operate several instances for different bundles. When a relevant update queues, Export becomes unavailable; confirmation applies to the current displayed checked program, delivered unchanged without regeneration or a second approval.
- **Extensions:** builders modify ordinary local extension code; makers call its operations on prints. Local edits survive replacement of release defaults; manuals, calls and regeneration select the same implementation. Saved artifacts remain viewable without code; regeneration names missing requirements. Exchange includes manifest, guidance, scripts/assets and available provenance/license, without execution or automatic promotion. No maker extension editor, sandbox or enforced IO permission claim.
- **Resource import:** acquisition returns an identified asset with available provenance/license; Geometry imports/repairs it, then Bundle accepts the result. Prefer saved assets to repeated downloads. Geometry-only STL import is valid. Public website instructions must not require users to know internal component wiring.
- **Wing:** document `npm run workspace:wing` where applicable: source-backed airfoil choices, sweep, camera/stage controls and live previews; full-plane display but wing-only printing, integrated winglets and upright Trace. Swept halves take separate straight rods; outer sections print on the flat winglet face. Save creates a new set under `Prints/wing-workspace` or `SAAM_DATA`, with design/export records and self-contained bundles carrying geometry, Trace, source and requirements. One agent request addresses the set; ordinary Studio work follows. New sets preserve edits; thermal settings/placement remain editable, construction changes require detachment. No live synchronization, flight qualification or delivered dihedral/twist claim.
- **Status and limits:** use [export contracts](../core/export/README.md) to distinguish implemented outputs from geometry/setup profiles. Keep ongoing physical qualification distinct from software checks. Material overlap, general support redesign, swept carriage collision avoidance and other [0.4.0 items](0.4.0.md) must not appear as delivered 0.3.1 capabilities.

For a compact technical explanation, use the nine responsibilities in the intent: Maker context, Geometry, Toolpath, Extensions, Bundle, Studio, Specialized workspaces, Export, and Settings. Explain their user-visible consequences first; link technical details. The provisional development map is not a conformance certificate.
