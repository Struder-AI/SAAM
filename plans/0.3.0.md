# SAAM 0.3.0 intent

Historical release intent, shipped 2026-10-01: **installation URL → desktop agent installs SAAM with an app icon → optional first-launch invite connects the update service → later updates use the in-app button.** This shipped independently of [0.3.1 architecture](0.3.1.md); [0.3.2](0.3.2.md) now owns next fixes.

- Testers install during chat by giving desktop Codex or desktop Claude Code a URL. Remove web-chat operation and its connection/session machinery; retain the local Studio–agent request/event channel and existing priority delivery. Alerts carry queued lower-priority observations; tool-result/explicit-read drains remain a review detail, separate from service diagnostics.
- SAAM works without activation. An invite entered in Studio enables official alpha updates and live diagnostics only. Unactivated use collects no diagnostics; missing/invalid codes or service failure never disable making, viewing or exporting. Replace the former chat relay with an update/diagnostics service, provisionally **Release & diagnostics service**. No offline grace/revocation subsystem.
- Keep user storage outside the replaceable installation, preserving bundles and local edits. A repository checkout is a separate developer workflow. Do not require 0.3.1's extension migration, neutral-engine refactor, architecture audit, instance-ownership work or tour redesign to finish before the installation trial.

## Shipped baseline

[Packaging](../packaging/README.md) and the [installation guide](../packaging/INSTALL.md) own current procedures and platform availability; [DEVLOG](../DEVLOG.md#2026-10-01--030-desktop-installation-tester-release) records the 0.3.0 Windows/Apple Silicon cut and exercised evidence. The old relay-dependent launcher and web-chat service were replaced. Native Mac acceptance remains in [0.3.2 follow-ups](0.3.2.md#inherited-unfinished-intent).

The optional service sends live SAAM operation/error/timing/system diagnostics under the implemented consent; omit transcripts, credentials and bulk files. Retention is 30 days. No preactivation capture, offline backlog or migration; failure never disables local making. Current service behavior and consent belong to [packaging](../packaging/README.md) and [service documentation](../relay/README.md), superseding draft wording here.
