# 0.3.1 tour policy

Approved for implementation by Nave's 2026-10-01 request to assign a worker
to create a better tour using its judgment. [Guided tour](../examples/prints/README.md)
owns the participant and agent instructions.

The core tour follows one editable part through a visible geometry change,
toolpath playback, a visible printing change, actual printer/material review,
and exact checked-file export. A participant without a matching printer may
finish by viewing. Other shapes, library navigation and STL import remain
available outside the core tour.

Studio supplies the task; the agent responds to requested edits and gives
concise process choices at the printing lesson. Back, exit and reopening the
same saved print preserve user control. Gates follow visible results, with no
arbitrary delay or required chat phrasing. A fresh tour creates a fresh copy.
One confirmation covers the current settings and exact displayed checked
program; a pending edit hides Export. Presentation uses short plain text and
blinking attention cues, including under reduced-motion preferences.
