SAAM — Maker Agent Context Map

Only the context a maker agent needs to help make a part. Maker is the first of three roles (maker → builder → developer); a maker uses skills, gives printing advice and operates Studio, and changes no shared code. Vertical spine = required reads; a red arrow = an action the agent runs to get the next required read; sideways = files that are mentioned (now the agent knows where they live); blue dashed = the files one command returns together: maker-onboarding returns MAKERS, the skill digest and print tools (and no maps), while the tour returns MAKERS plus tour participation instead of onboarding. Use read-skill ID --maker for a selected skill (maker is also the default). Click a box to open the file. Hover to isolate its links.

Grey reference boxes are docs a maker consults only when the part needs them; hover each for its maker scope. Makers change no shared code and read no dev map, so implementation detail is deliberately absent here. When a request needs a build, the maker escalates to builder (tan box, lower left) and runs builder-onboarding. For an existing Studio print the first action is instead begin-studio-work, which returns the print, revision and request context but no manuals — load missing maker or skill context after it. A tour replaces onboarding: studio/server.mjs --toolkit start-tour --no-open delivers MAKERS plus tour participation and must run before any read.
