SAAM — Maker Agent Context Map

Only the context a maker agent needs to help make a part. Maker is the first of three roles (maker → builder → developer); a maker uses skills, gives printing advice and operates Studio, and changes no shared code. Vertical spine = required reads; a red arrow = an action the agent runs to get the next required read; sideways = files that are mentioned (now the agent knows where they live); blue dashed = the three files maker-onboarding delivers together. Click a box to open the file. Hover to isolate its links.

✂ Yellow boxes are shared docs the maker reads only a slice of — hover them for the maker slice and where the rest now lives. The builder/developer slices have been separated: cleanly-detachable dev-only sections were moved to DEVELOPER-CONTEXT.md, and interwoven ones are catalogued there for the maps to absorb. When a request needs a build, the maker escalates to builder (tan box, lower left) and runs builder-onboarding. For an existing Studio print the first action is instead begin-studio-work; a tour skips onboarding and launches studio/server.mjs --toolkit start-tour first.
