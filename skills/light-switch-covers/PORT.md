# Light Switch Covers port

Adapted from Timothy Keller TK-DEV `f4c84235735a645d80b36b4a179554b0b27913d1`,
`workspaces/light-switch-covers/` (introduced at `67e59b35`). Gallery, catalog,
research, parameter specification and example remain in one portable workspace.
The old standalone server and direct native/private imports have been removed.

Construction uses shared Geometry `buildGeometry`/`constructSolids` and the
declared Text dependency’s `compileText`. Final meshes and ordinary Slice assignments
are self-contained Bundle contributions. Saved design is historical provenance;
Studio owns subsequent editing, settings, generation and Export.

Software evidence: all four lettering modes produce actual mesh previews and
validate as current recipes through the workspace factory. Source runtime and
host acceptance evidence is recorded separately. Physical fit and electrical
material qualification remain unverified.

Original requester attribution was unconfirmed; Codex authored original research,
specification and prototype. TK-DEV supplied the source. Original community/no
designated maintainer/no Struder support commitment status remains explicit.
Font bytes, identity and SIL Open Font License remain in `fonts/`.
International mounting families are references; general retained-cover overlays
remain planned. Current support and usage live in [SKILL.md](SKILL.md).
