# Abel font provenance

`Abel-Regular.ttf` is the unmodified Abel font from the
[Google Fonts Abel directory](https://github.com/google/fonts/tree/main/ofl/abel),
downloaded 2026-09-12 for SAAM's original text fixture. TK's workspace selected
it for labels; this extension carries its own copy and [SIL Open Font License](OFL.txt).
