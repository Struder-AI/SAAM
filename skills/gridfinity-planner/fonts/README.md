# Label font

`Abel-Regular.ttf` is the unmodified Abel font from the
[Google Fonts Abel directory](https://github.com/google/fonts/tree/main/ofl/abel),
the same file SAAM's text extension keeps as its test fixture and the
light-switch-covers workspace bundles for its labels (downloaded 2026-09-12). Its [SIL Open Font License](OFL.txt) is retained here. The planner
names it as the label font in its interface; labels are constructed by the text
extension, which stores the font bytes in each bundle.

SHA-256: `8809dcad25318225052f88333e208c5aad4adcb7b2c934c135735ec19aa410b4`.
