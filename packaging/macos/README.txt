SAAM for macOS

Extract the whole ZIP, then open Install SAAM.command.
SAAM lives in ~/SAAM: app is replaced by updates; Prints, extensions and
state persist. Earlier application/data folders migrate, with recoverable
old files in state/migration. The Finder launcher is ~/Applications/SAAM.app.

Start from the SAAM icon; use its menu-bar menu for Open Studio, Update and
Quit. Closing a Studio tab leaves SAAM running. Both clients get skills and permissions, even if absent. Restart existing clients
after installation to discover the saam command and skill. The agent handles
client setup and repairs. Claude Code requires 2.1.285 or later; the alpha invite
is optional.

Run bash ~/SAAM/app/packaging/macos/uninstall.sh to remove app files and
shortcuts. Your prints, extensions, settings and logs stay in ~/SAAM.
