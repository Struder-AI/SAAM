SAAM for Windows

Extract the whole ZIP, then double-click Install SAAM.cmd.
SAAM lives in C:\SAAM: app is replaced by updates; Prints, extensions and
state persist. Earlier application/data folders migrate, with recoverable
old files in state\migration. The home allows other Windows users to write.

Start from the SAAM shortcut; use the tray menu for Open Studio, Update and
Quit. Closing a Studio tab leaves SAAM running. Both clients get skills and permissions, even if absent. Restart existing clients
after installation to discover the saam command and skill. The agent handles
client setup and repairs. The alpha invite is optional.

Use Uninstall SAAM on the Start Menu to remove the app, shortcuts and client
setup. Your prints, extensions, settings and logs stay in C:\SAAM.
